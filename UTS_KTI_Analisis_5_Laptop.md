Saat menjalankan compiler C/C++, Docker container, atau kompilasi Android Studio yang menuntut komputasi matematis linier di seluruh thread, 6 core penuh seri H tidak mengalami thermal drop sedalam core seri U (15W). Namun, untuk multitasking aplikasi latar belakang (seperti membuka 40 tab Chrome bersamaan sambil menjalankan Spotify dan IDE), arsitektur hybrid **Intel Core i5-1335U (10 Core)** juga sangat efisien karena thread background ditangani oleh 8 Efficient-cores tanpa mengganggu P-core.

  $$\text{Performa} = \text{Jumlah Core} \times \text{IPC (Instructions Per Cycle)} \times \text{Clock Frequency}$$  
  Banyaknya core hanya berpengaruh jika perangkat lunak mendukung paralelisasi (multithreading) sesuai *Hukum Amdahl*. Jika aplikasi bersifat single-threaded (misal pengeksekusian script sekuensial sederhana), prosesor 6-core dengan clock 4.5 GHz dan IPC tinggi akan jauh lebih kencang daripada prosesor 10-core yang mayoritas terdiri atas E-core berkecepatan 0.9–3.4 GHz. Selain itu, batas termal (TDP throttling) pada prosesor hemat daya sering memaksa clock turun saat semua core terbebani penuh.

### 2. CPU Cache: L1, L2, dan L3

#### Identifikasi Ukuran Cache:
* **AMD Ryzen 5 6600H (Laptop A & B):** L1 = 384 KB (6x 32KB I-Cache + 6x 32KB D-Cache), L2 = 3 MB (6x 512 KB per core), L3 = 16 MB (Shared Monolithic CCX).
* **Intel Core i5-12450H (Laptop C):** L1 = 640 KB, L2 = 7 MB (4x 1.25MB untuk P-cores + 2MB shared untuk 4x E-core cluster), L3 = 12 MB Intel Smart Cache (Shared).
* **Intel Core i5-1335U (Laptop D & E):** L1 = 960 KB, L2 = 12 MB (2x 1.25MB P-cores + 2x 2MB E-core clusters), L3 = 12 MB Intel Smart Cache (Shared).

#### Penjelasan Teknis:
* **Fungsi Cache:** Memori SRAM super cepat berlatensi sangat rendah di dalam die CPU yang berfungsi menyimpan instruksi dan data yang sering digunakan secara berulang untuk meminimalisasi *von Neumann bottleneck* (keterlambatan waktu tunggu saat CPU mengambil data dari DRAM utama).
* **Perbedaan L1, L2, dan L3:**
  1. *Cache L1:* Berada langsung di dalam core eksekusi. Kapasitas paling kecil (32–64 KB per core), latensi terendah (~1 nanodetik / 4-5 clock cycles), kecepatan setara clock CPU.
  2. *Cache L2:* Terletak berdampingan dengan core individual (atau per kluster). Kapasitas menengah (512 KB – 1.25 MB per core), latensi ~3–4 nanodetik (~12–14 cycle).
  3. *Cache L3:* Memori bersama (*shared*) yang diakses oleh seluruh core dalam satu die. Kapasitas terbesar (12–16 MB), kecepatan lebih lambat dari L2 (latensi ~10–20 nanodetik), tetapi masih ratusan kali lebih cepat daripada RAM utama.
* **Hubungan Cache dengan RAM dan Pemrosesan Data:** Ketika CPU membutuhkan data, ia mencari secara hierarkis: L1 $\rightarrow$ L2 $\rightarrow$ L3. Jika ditemukan (*Cache Hit*), eksekusi berlangsung instan. Jika tidak ada (*Cache Miss*), CPU harus menjangkau DRAM melalui memory controller via bus sistem yang memakan waktu ~60–80 nanodetik (ratusan cycle jeda menganggur). Cache yang lebih besar (seperti 16MB L3 pada Ryzen 6600H) secara dramatis mereduksi cache miss rate saat kompilasi program.

#### Pertanyaan Analisis RAM:
* **a. Apakah RAM 16 GB cukup untuk kebutuhan pada skenario kasus (mahasiswa IT)?**  
  *Jawaban:* **Cukup untuk tingkat awal hingga menengah (tahun 1–3).** Asumsi: Menjalankan Windows 11 (~4 GB idle), browser dengan 15 tab dokumentasi (~2.5 GB), VS Code + compiler/Node.js (~2 GB), dan satu container Docker ringan (~2 GB), memakan total ~10.5–12 GB RAM. Sistem masih memiliki ruang sisa tanpa menyentuh *paging file* SSD.
* **b. Dalam kondisi apa RAM 32 GB lebih menguntungkan?**  
  *Jawaban:* Ketika menjalankan **multiple virtual machines (VM VirtualBox/VMware)** untuk praktikum jaringan, emulator Android Studio bersamaan dengan IDE berat, atau saat melatih model machine learning lokal dan data wrangling dataset raksasa menggunakan pustaka Pandas/NumPy.
* **c. Apa pengaruh konfigurasi single-channel dan dual-channel terhadap kinerja?**  
  *Jawaban:* Dual-channel menggandakan lebar bus data dari 64-bit menjadi 128-bit, melipatgandakan *memory bandwidth*. Pada laptop tanpa GPU diskrit, iGPU (seperti Radeon 660M atau Iris Xe) meminjam memori sistem sebagai VRAM. Konfigurasi dual-channel meningkatkan performa iGPU hingga **40%–70%** dibanding single-channel dan mencegah CPU bottleneck saat memproses data bervolume besar.
* **d. Apa konsekuensi jangka panjang apabila RAM tidak dapat di-upgrade?**  
  *Jawaban:* Menimbulkan risiko *planned obsolescence*. Dalam 3–5 tahun, kebutuhan memori sistem operasi dan software dipastikan meningkat. Jika beban kerja melebihi 16 GB, OS terpaksa melakukan swapping data ke SSD (*virtual memory*), yang menyebabkan penurunan performa drastis dan mempercepat degradasi umur baca-tulis (*TBW wear*) dari SSD.

#### Identifikasi:
* **Laptop A & B (AMD Radeon 660M):** Integrated GPU | Arsitektur RDNA 2 (6 Compute Units / 384 Shaders) | Clock hingga 1900 MHz | VRAM: Shared sistem dinamis | Dukungan DirectX 12 Ultimate, Vulkan 1.3, hardware raytracing dasar, AV1 decode.
* **Laptop C (Intel UHD Graphics 12th Gen):** Integrated GPU | Arsitektur Alder Lake GT1 (64 Execution Units) | Shared VRAM | DirectX 12.1, Intel QuickSync Video.

#### Pertanyaan Analisis GPU:
* **a. Apa perbedaan integrated GPU dan dedicated GPU?**  
  *Jawaban:* Integrated GPU (iGPU) menyatu di dalam silikon CPU die, berbagi daya (TDP) dan memori utama sistem (DRAM) dengan CPU tanpa memiliki memori sendiri. Dedicated GPU (dGPU) adalah chip grafis terpisah dengan papan sirkuit tersendiri, sistem pendingin mandiri, dan VRAM khusus berkecepatan ultra-tinggi (seperti GDDR6) dengan konsumsi daya jauh lebih besar.
* **b. Apakah semua mahasiswa yang belajar pemrograman membutuhkan dedicated GPU?**  
  *Jawaban:* **Tidak.** Mayoritas kurikulum informatika (algoritma struktur data, rekayasa web, basis data, jaringan, backend development) hanya bertumpu pada CPU dan RAM. Dedicated GPU hanya mutlak dibutuhkan oleh mahasiswa peminatan game development (Unity/Unreal Engine 5), render animasi 3D (Blender), atau pelatihan deep learning skala berat.
* **c. Bagaimana pilihan GPU memengaruhi konsumsi daya, suhu, harga, dan daya tahan baterai?**  
  *Jawaban:* Dedicated GPU menambah konsumsi daya 35W–100W+, menghasilkan panas tinggi yang membutuhkan dua kipas pendingin besar, membuat bobot laptop di atas 2 kg, memperpendek daya tahan baterai menjadi 2–3 jam saja, dan meningkatkan harga jual laptop. Sebaliknya, iGPU hemat daya (<15W), dingin, memungkinkan baterai bertahan 6–9 jam, dan menjaga harga tetap di bawah Rp 9 juta.
* **d. Untuk pengolahan data atau AI, kapan GPU yang lebih kuat benar-benar diperlukan?**  
  *Jawaban:* GPU kuat (terutama yang memiliki NVIDIA Tensor Cores dan CUDA) mutlak diperlukan pada tahap **Training Model Deep Learning** (CNN, Transformer, LLM fine-tuning) dengan backpropagation yang melibatkan perkalian matriks secara masif. Untuk sekadar tahap inferensi atau data science tabular (Scikit-Learn, Pandas), CPU performa tinggi dan RAM besar sudah sangat mencukupi.

#### Pertanyaan Analisis Storage:
* **a. Apa perbedaan HDD, SATA SSD, dan NVMe SSD?**  
  *Jawaban:*
  * *HDD (Hard Disk Drive):* Mekanikal dengan piringan magnetik berputar (5400/7200 RPM), throughput lambat (~100–150 MB/s), latensi tinggi (10–15 ms) karena jeda mekanis head.
  * *SATA SSD:* Memori flash NAND berbasis protokol AHCI lawas melalui antarmuka SATA III, throughput mentok di ~550 MB/s, latensi ~0.1 ms.
  * *NVMe SSD:* Memori flash langsung terhubung ke jalur PCIe bus prosesor dengan antarmuka PCIe x4, mendukung protokol NVMe antrian paralel tinggi (64.000 antrian), kecepatan tembus 2.000–7.000+ MB/s, latensi sangat rendah (~0.02 ms).
* **b. Apakah kapasitas SSD yang lebih besar selalu berarti lebih cepat?**  
  *Jawaban:* **Sering kali ya, hingga kapasitas tertentu.** SSD berkapasitas lebih besar (misal 1TB vs 256GB) memiliki chip NAND die lebih banyak yang terhubung secara paralel ke multi-kanal controller, menghasilkan throughput baca-tulis paralel yang lebih tinggi serta ukuran dynamic SLC cache yang lebih luas sebelum kecepatan melambat saat transfer file masif.
* **c. Bagaimana storage memengaruhi waktu booting, pembukaan aplikasi, dan transfer berkas?**  
  *Jawaban:* Latensi seek-time yang hampir nol dan tingginya nilai IOPS (Input/Output Operations Per Second) pada SSD NVMe memotong waktu booting sistem operasi dari ~60 detik (HDD) menjadi ~8–12 detik. Pembukaan IDE dan transfer dataset besar terjadi seketika karena throughput bus PCIe mencapai gigabyte per detik.
* **d. Untuk anggaran yang sama, lebih baik memilih SSD 512 GB dengan spesifikasi lain lebih tinggi atau SSD 1 TB dengan spesifikasi lain lebih rendah?**  
  *Jawaban:* **Memilih SSD 512 GB dengan spesifikasi CPU/RAM/Bodi yang lebih tinggi.** Alasan teknis: SSD adalah komponen modular yang paling mudah dan murah ditingkatkan di kemudian hari. Sebaliknya, CPU yang lambat atau RAM yang tersolder permanen tidak dapat diganti seumur hidup laptop.

* **a. Apa perbedaan utama Wi-Fi 5, Wi-Fi 6, dan Wi-Fi 7?**
